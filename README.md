# supprimer-mail-double-outlook

Voici un script powershell avec interface graphique (WinForms) permettant de sélectionner un dossier dans Outlook et de supprimer les mails en double dans ce dossier.

#🧰 Mode d'emploi

Lance Outlook avant de lancer ce script.

Copie-colle ce script dans un fichier .ps1

Exécute-le avec PowerShell.

Clique sur "Choisir un dossier Outlook", sélectionne un dossier (Inbox, Sent, etc.).

Le script supprime tous les doublons détectés.
